Download / Install App

Accounts Orbit desktop pe alag setup file nahi chahiye. Website kholo, Chrome/Edge se Install karo — desktop icon ban jayega, jaise normal app.

1. App kholo (sabse pehle)

Login / Sign up ke baad poori billing app chalegi — laptop, desktop, phone sab pe.

Open Accounts Orbit Create free account

2. Desktop pe app jaisa install

  1. Upar Open Accounts Orbit dabao (Chrome ya Edge use karo).
  2. Address bar ke right side ⊕ Install icon dikhega — uspe click.
  3. Ya menu ⋮ → Install Accounts Orbit / Apps → Install this site as an app.
  4. Desktop / Start Menu pe icon aa jayega. Agli baar wahi click karke chalao.

Phone: browser menu → Add to Home screen / Install app.
