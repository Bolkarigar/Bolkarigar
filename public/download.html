2. Blue screen aaye to yeh karo

Windows protected your PC Microsoft ka normal check hai. App kharab nahi hai. Don't run mat dabao.
  1. Setup file par double-click karo.
  2. Neela box aaye to chhota link More info dabao.
  3. Phir Run anyway dabao.
  4. Accounts Orbit khul jaayegi.

3. Warning bilkul na aaye?

Woh tab hota hai jab Windows signed certificate hota hai. Abhi setup unsigned hai, isliye Microsoft ek baar poochta hai. More info → Run anyway ke baad app normal chalti hai.
